# Shmuelie.Utilities

General developer utilities for PowerShell, .NET tools, Python packages, VS
Code, Windows Terminal, services, applications, and WPR tracing.

**Version:** 0.1.0

```powershell
Install-PSResource Shmuelie.Utilities
Import-Module Shmuelie.Utilities
```

See the [module reference](../../docs/modules.md#shmuelie-utilities), the
[repository overview](../../README.md), and the [changelog](CHANGELOG.md) for
commands, examples, and requirements.
