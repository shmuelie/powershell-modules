# Shmuelie.Utilities

General developer utilities for PowerShell, .NET tools, Python packages, VS Code,
Windows Terminal, Windows services, installed applications, and WPR tracing.

```powershell
Install-PSResource Shmuelie.Utilities
Import-Module Shmuelie.Utilities
```

The module targets PowerShell 7.4 or later. Windows-only commands report their
platform requirements in command help.
