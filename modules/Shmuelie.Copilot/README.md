# Shmuelie.Copilot

GitHub Copilot CLI session, plugin, marketplace, and MCP helpers, plus the
`Start-Copilot` launcher (alias `copilot`).

**Version:** 0.2.0

```powershell
Install-PSResource Shmuelie.Copilot
Import-Module Shmuelie.Copilot
Start-Copilot
```

See the [module reference](../../docs/modules.md#shmuelie-copilot), the
[repository overview](../../README.md), and the [changelog](CHANGELOG.md) for
commands, examples, and requirements.
